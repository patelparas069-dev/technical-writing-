# Technical Presentation Skills

Guide to planning, designing, and delivering effective technical presentations.

## Presentation Planning

### Define Your Audience
- **Technical level**: Experts, students, general audience?
- **Prior knowledge**: What do they already know?
- **Expectations**: What do they want to learn?
- **Size**: Small group or large lecture?

### Set Clear Objectives
- What should audience learn?
- What action should they take?
- One main message per presentation

### Structure Your Content
1. **Introduction** (10%)
   - Grab attention
   - State objectives
   - Preview structure

2. **Body** (80%)
   - 3-5 main points
   - Logical flow
   - Supporting evidence

3. **Conclusion** (10%)
   - Summarize key points
   - Call to action
   - Q&A invitation

## Slide Design Principles

### Visual Hierarchy
- **Title**: Largest, most prominent
- **Main points**: Secondary size
- **Details**: Smallest, sparse

### The 6-6 Rule
- Maximum 6 bullet points per slide
- Maximum 6 words per bullet
- (Guidelines, not absolute rules)

### Color and Contrast
- **High contrast**: Dark text on light background
- **Consistent palette**: 2-3 colors max
- **Color meaning**: Red=important, Green=positive
- **Accessibility**: Consider color blindness

### Typography
- **Font size**: Minimum 24pt for body text
- **Font choice**: Sans-serif for slides (Arial, Helvetica)
- **Consistency**: Same fonts throughout
- **Emphasis**: Bold, not underline

### White Space
- Don't fill every pixel
- Margins and padding
- One idea per slide
- Let content breathe

## Content Guidelines

### Text
- **Bullet points**, not paragraphs
- **Keywords**, not full sentences
- **Active voice**: "We found" not "It was found"
- **Present tense**: "This shows" not "This showed"

### Images and Graphics
- **High quality**: No pixelated images
- **Relevant**: Support your message
- **Simple**: Avoid cluttered diagrams
- **Cited**: Give image credits

### Equations and Code
- **Large enough** to read
- **Explained**: Don't just show
- **Highlighted**: Draw attention to key parts
- **Context**: Why is this important?

### Data Visualization
- **Clear labels**: Axis labels, units
- **Simple**: One message per chart
- **Colors**: Meaningful and distinct
- **Title**: What does chart show?

## Delivery Tips

### Before Presentation
- **Practice**: 3-5 times minimum
- **Time yourself**: Stay within limit
- **Test equipment**: Projector, clicker, mic
- **Backup plan**: USB drive, cloud backup
- **Arrive early**: Setup and test

### During Presentation
- **Eye contact**: With audience, not screen
- **Voice**: Clear, loud enough, varied pace
- **Body language**: Open, confident
- **Pace**: Not too fast
- **Pause**: After key points
- **Engage**: Ask questions, check understanding

### Handling Questions
- **Listen carefully**: Understand question
- **Repeat question**: Ensure everyone heard
- **Honest**: Say "I don't know" if needed
- **Brief answers**: Don't give another presentation
- **Defer if needed**: "Let's discuss after"

## Common Mistakes to Avoid

### Content Mistakes
- ✗ Too much text
- ✗ Reading slides word-for-word
- ✗ Too many slides
- ✗ Unclear objectives
- ✗ No clear structure

### Design Mistakes
- ✗ Low contrast colors
- ✗ Tiny fonts
- ✗ Distracting animations
- ✗ Inconsistent formatting
- ✗ Cluttered slides

### Delivery Mistakes
- ✗ Turning back to audience
- ✗ Speaking too fast
- ✗ Going over time
- ✗ Apologizing excessively
- ✗ Ignoring questions

## Presentation Checklist

### Content
- [ ] Clear objectives stated
- [ ] Logical flow
- [ ] Key points emphasized
- [ ] Conclusion summarizes
- [ ] Sources cited

### Design
- [ ] Consistent theme
- [ ] Readable fonts (≥24pt)
- [ ] High contrast
- [ ] Minimal text per slide
- [ ] Quality images

### Technical
- [ ] Tested on presentation computer
- [ ] Backup copy available
- [ ] All media files included
- [ ] Clicker batteries checked
- [ ] Timer/clock visible

### Delivery
- [ ] Practiced multiple times
- [ ] Timed correctly
- [ ] Questions anticipated
- [ ] Handouts prepared (if needed)
- [ ] Calm and confident

- WYSIWYG interface
- Easy collaboration (Slides)
- Many templates

### Prezi
- Non-linear, zooming interface
- Engaging for some audiences
- Can be distracting if overused

## Presentation Types

### Conference Talk
- 15-20 minutes typical
- Formal
- Research focused
- Q&A at end

### Class Presentation
- 10-15 minutes typical
- Educational
- Clear learning outcomes
- Interactive

### Thesis Defense
- 30-45 minutes
- Comprehensive
- Expect detailed questions
- Formal

### Lightning Talk
- 5 minutes or less
- One key message
- High energy
- Minimal slides
