# Vector Operations Demo

This repository demonstrates Git branching concepts using a vector dot product example.

## Purpose

Educational demonstration of:
- Git branch creation and management
- Merge conflict resolution
- Parallel algorithm development

## Files

- `vecadd.py` - Vector dot product implementation
- `README.md` - This file

## Usage

```bash
python3 vecadd.py
```

## Git Exercise

This repository is part of Assignment 9 (Git Branching) for the Technical Writing course.

Follow the exercise steps in `commands.md` and `exercise_report.md` to recreate the branching workflow.

## Note

To initialize this as a Git repository and follow the exercise:

```bash
cd demo_repository
git init
git add .
git commit -m "Initial commit"
# Then follow commands.md
```
