# Google Docs - Collaborative Document Editing

Guide to Google Docs for collaborative writing and document management.

## What is Google Docs?

Google Docs is a web-based word processor that enables real-time collaboration on documents.

**Key features**:
- Cloud-based (access anywhere)
- Real-time collaboration
- Automatic saving
- Version history
- Commenting and suggestions
- Free with Google account

## Basic Features

### Creating Documents
1. Go to https://docs.google.com
2. Click "+ New" or "Blank document"
3. Document auto-saves to Google Drive

### Text Formatting
- **Bold**: Ctrl+B
- *Italic*: Ctrl+I
- Underline: Ctrl+U
- Font, size, color from toolbar

### Paragraph Formatting
- Headings: Use "Normal text" dropdown
- Lists: Bullet or numbered
- Alignment: Left, center, right, justify
- Line spacing: From Format menu

## Collaboration Features

### Sharing
1. Click "Share" button (top right)
2. Add email addresses
3. Set permissions:
   - **Viewer**: Can view only
   - **Commenter**: Can add comments
   - **Editor**: Can edit

### Comments
1. Select text
2. Click comment icon or Ctrl+Alt+M
3. Type comment
4. Collaborators can reply
5. Mark as resolved when done

### Suggesting Mode
1. Top right: Editing → Suggesting
2. Changes appear as suggestions
3. Owner can accept or reject
4. Like "track changes" in Word

### Version History
1. File → Version history → See version history
2. View all past versions
3. Restore previous version if needed
4. Named versions for milestones

## Tables and Images

### Tables
- Insert → Table
- Choose rows and columns
- Right-click for table properties

### Images
- Insert → Image
- From computer, URL, Drive, or Camera
- Resize and position

### Links
- Ctrl+K to insert link
- Link to websites or other Docs

## Advanced Features

### Table of Contents
- Insert → Table of contents
- Auto-generated from headings
- Updates automatically

### Footnotes
- Insert → Footnote
- Appears at bottom of page

### Page Setup
- File → Page setup
- Margins, orientation, page size
- Page numbers

### Export Options
- File → Download
- PDF, Word (.docx), Plain text, etc.

## Best Practices

1. **Use headings**: Structure document properly
2. **Enable suggestions**: For collaborative editing
3. **Comment instead of editing**: When unsure
4. **Name versions**: Before major changes
5. **Share with specific people**: Don't make public unless needed
6. **Use templates**: For consistent formatting

## Google Docs vs LaTeX

| Feature | Google Docs | LaTeX |
|---------|-------------|-------|
| Learning curve | Easy | Steep |
| Collaboration | Excellent | Via Git |
| Math equations | Limited | Excellent |
| Formatting | WYSIWYG | Code-based |
| Version control | Built-in | External (Git) |
| Best for | General docs, collaboration | Technical docs, publications |

## When to Use Google Docs

**Good for**:
- Group projects with non-technical members
- Quick collaborative writing
- Documents needing frequent review
- Shared meeting notes
- Draft documents

**Not ideal for**:
- Complex mathematical content
- Long technical documents
- Documents requiring precise formatting
- Publications requiring LaTeX format

## Tips

- **Keyboard shortcuts**: See Help → Keyboard shortcuts
- **Explore menu**: Experiment with Insert and Format menus
- **Add-ons**: Tools → Add-ons for extended functionality
- **Offline mode**: Available with Google Drive desktop app
- **Voice typing**: Tools → Voice typing (Chrome only)
